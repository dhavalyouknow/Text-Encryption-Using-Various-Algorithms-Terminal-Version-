**Title: Terminal-Based Text Encryption Tool**

**Description:**
This is a Linux terminal-based Python program that allows users to encrypt and decrypt text using multiple classical encryption algorithms. The project helps beginners learn the logic behind cryptographic ciphers while gaining hands-on programming experience in Linux. Users can select from several ciphers such as Caesar Cipher, Vigenère Cipher, and Railfence Cipher, input a key, and encrypt or decrypt text directly in the terminal.

**Key Features:**

Encrypt and decrypt text using multiple classical ciphers.

Supports Caesar, Vigenère, and Railfence ciphers (extendable to more).

Terminal-based interface — no web or GUI needed.

Optional: Save encrypted/decrypted text to a file.

**Learning Outcomes:**

Understand the mechanics of classical encryption algorithms.

Gain experience in Python programming and Linux terminal usage.

Learn how to structure a modular program with functions.

Build confidence to later explore advanced cryptography.
